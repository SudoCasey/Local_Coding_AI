# Local Coding AI 0.1.0

**Asset:** `local-coding-ai-0.1.0.vsix`  
**Tag:** `v0.1.0`  
**Download:** https://github.com/SudoCasey/Local_Coding_AI/releases/tag/v0.1.0

## What's included

- Offline Ollama-powered chat sidebar for VS Code
- Auto Mode Smart Router with Fast / Primary / Heavy role panel (swap & download)
- In-extension Ollama context window controls (`num_ctx`)
- Concurrent model downloads with progress
- Model update checks with name, version/tag, and library notes
- Free VRAM, Compact, Clear Context, Clean RAM controls
- Silent background `ollama serve` launch (no popup window)
- Workspace-sandboxed editor attach / apply / insert actions
- Resource cleanup on extension deactivate (timers, pulls, context, VRAM unload)
- Optional Docker GPU compose stack under `docker/`

## Install

```powershell
code --install-extension local-coding-ai-0.1.0.vsix
```
