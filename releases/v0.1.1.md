## Install

```powershell
code --install-extension local-coding-ai-0.1.1.vsix
```

Or in VS Code: **Extensions** → **Install from VSIX…**

## What's included

- Launch Ollama via the Windows tray app (`ollama app.exe`) so GPU runners load without hanging larger models
- Stop CMD console flashes from detached `ollama.exe serve` / startup API probes
- Chat load status + timeout when a model (e.g. 7B) never starts streaming
- Free other loaded runners before switching models (`ensureModelSlot`)
- Security hardening: loopback `ollamaUrl` confirmation, fail-closed workspace sandbox, escaped markdown / Apply confirm
- Efficiency: shared hardware poll, buffered stream render, Docker bind to `127.0.0.1`
